
# Windows Event Log Analysis

## Objective
To understand Windows Event Viewer and analyze
important Windows Security Events.

## Event ID 4624
- Meaning: Successful Logon.
- What I observed: I found successful login
  events in Windows Security Logs.

## Event ID 4625
- Meaning: Failed Logon.
- What I observed: I searched for failed
  login attempts in Security Logs.

## Event ID 4688
- Meaning: New Process Created.
- What I observed: I searched for process
  creation events after opening Notepad.

## Tools Used
- Windows Event Viewer
- Windows Security Logs
- Notepad

## Learning Outcomes
- Learned about Windows Event Viewer.
- Learned to identify successful and failed logins.
- Learned about process creation events.
